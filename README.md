# Shankh One Solution Website

Files:
- index.html
- style.css
- script.js
- logo.png

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload all four files to the repository root.
3. Open Settings -> Pages.
4. Choose "Deploy from a branch", select the main branch and root folder.
5. Save. GitHub will provide the live website link.

The website is responsive for mobile and desktop and includes phone, email and WhatsApp buttons.
